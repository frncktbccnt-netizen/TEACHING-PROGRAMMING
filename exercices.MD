# 📚 Défis HTML & CSS

Voici une série de défis classés du plus simple au plus avancé pour permettre aux étudiants de mettre en pratique les notions apprises.

---

# 🟢 Défi 1 : Ma première page HTML

## Objectif

Créer une page HTML contenant :

- Un titre principal (`<h1>`)
- Un sous-titre (`<h2>`)
- Deux paragraphes (`<p>`)
- Une ligne horizontale (`<hr>`)
- Un saut de ligne (`<br>`)
- Un texte en **gras** (`<strong>`)
- Un texte en _italique_ (`<em>`)

### Bonus

- Soulignez un mot avec la balise `<u>`.

---

# 🟢 Défi 2 : Présente-toi

## Objectif

Créer une page qui contient :

- Un titre
- Un paragraphe qui te présente
- Ton nom en **gras**
- Ton métier ou le métier de tes rêves en _italique_
- Ton pays souligné
- La formule **H₂O**
- La formule **x²**

Utilise les balises HTML appropriées.

---

# 🟢 Défi 3 : Les images

## Objectif

Créer une page contenant :

- Un titre
- Un paragraphe décrivant ton animal préféré
- Une image de cet animal

L'image doit avoir :

- Une largeur de **300 px**
- Un attribut `alt` correctement renseigné

---

# 🟢 Défi 4 : Les liens

## Objectif

Créer une page contenant trois liens :

- Google
- YouTube
- GitHub

Chaque lien doit s'ouvrir dans un nouvel onglet.

---

# 🟢 Défi 5 : Les listes

## Objectif

Créer :

- Une liste non ordonnée (`<ul>`) contenant tes **5 plats préférés**.
- Une liste ordonnée (`<ol>`) décrivant ta **routine quotidienne**.

---

# 🟢 Défi 6 : Formulaire d'inscription

## Objectif

Créer un formulaire contenant :

- Nom complet
- Adresse e-mail
- Mot de passe
- Âge
- Sexe (boutons radio)
- Langages de programmation préférés (cases à cocher)
- Pays (liste déroulante)
- Biographie (`<textarea>`)
- Bouton **Envoyer**
- Bouton **Réinitialiser**

---

# 🟢 Défi 7 : Carte de profil

## Objectif

Créer une carte de présentation contenant :

- Une photo
- Ton nom
- Ton métier
- Une courte biographie
- Ton adresse e-mail
- Un bouton **Me contacter**

---

# 🔵 Défi CSS 1 : Styliser un paragraphe

## Objectif

Appliquer les styles suivants à tous les paragraphes :

- Texte bleu
- Taille : **20 px**
- Police : **Arial**
- Fond gris clair
- `padding` : **15 px**
- Bordure noire de **2 px**
- Coins arrondis

---

# 🔵 Défi CSS 2 : Styliser les champs de saisie

## Objectif

Appliquer les styles suivants aux champs `<input>` :

- Largeur : **300 px**
- Hauteur : **40 px**
- `padding` : **10 px**
- Bordure grise
- Coins arrondis

### Bonus

Lorsque l'utilisateur clique dans le champ, la bordure devient bleue.

---

# 🔵 Défi CSS 3 : Styliser un bouton

## Objectif

Créer un bouton avec :

- Fond bleu
- Texte blanc
- Sans bordure
- `padding`
- Coins arrondis
- Curseur en forme de main (`cursor: pointer`)

### Bonus

- Au survol (`:hover`), le bouton devient vert.
- Lors du clic (`:active`), le bouton devient orange.

---

# 🔵 Défi CSS 4 : Les pseudo-classes

## Objectif

Créer un paragraphe tel que :

- La première lettre est rouge.
- La première lettre mesure **40 px**.
- Au survol (`:hover`), le texte devient bleu.
- Au clic (`:active`), le texte devient violet.

---

# 🟣 Projet Final : Formulaire d'inscription étudiant

## Objectif

Créer une page d'inscription complète.

## Partie HTML

La page doit contenir :

- Un titre
- Une courte description
- Une image
- Un formulaire

Le formulaire doit contenir :

- Nom complet
- Adresse e-mail
- Mot de passe
- Date de naissance
- Numéro de téléphone
- Sexe
- Pays
- Langages de programmation préférés
- Biographie
- Bouton **Envoyer**
- Bouton **Réinitialiser**

## Partie CSS

Appliquer les styles suivants :

- Centrer le formulaire.
- Ajouter une couleur de fond à la page.
- Styliser le titre.
- Styliser tous les champs `<input>`.
- Styliser le `<textarea>`.
- Styliser les boutons.
- Ajouter les effets `:hover` et `:active` sur les boutons.
- Utiliser au moins **3 classes CSS**.
- Utiliser `::first-letter` sur le paragraphe de présentation.
